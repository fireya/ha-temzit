# Temzit Hydromodule

Community-интеграция для Home Assistant, опрашивающая
гидромодуль ТЭМЗИТ по TCP. Показывает температуры, проток, компрессоры,
мощность, состояние, расписания и часы устройства.

> Интеграция только читает состояние (read-only). Запись настроек пока не реализована.
> Проект не связан с производителем.

## Требования

- Home Assistant 2024.1+
- Гидромодуль с доступом по TCP (по умолчанию порт `333`)
- Интеграция опрашивает устройство раз в 15 секунд (лимит устройства ~1 запрос/10 с)

## Установка

### Через HACS

1. HACS → **Интеграции** → кнопка **⋮** (сверху справа) → **Download object**.
2. Вставьте URL этого репозитория и выберите `temzit`.
3. Перезагрузите Home Assistant.

### Вручную

1. Скопируйте папку `custom_components/temzit/` в `<конфиг HA>/custom_components/`.
2. Перезапустите Home Assistant.

## Настройка

Настройки → Устройства и сервисы → **Добавить интеграцию** → **Temzit**.
Укажите IP-адрес (или имя хоста) устройства и TCP-порт.

## Сущности

| Тип | Что показывает |
| --- | --- |
| sensor | улица / дом / подача / обратка / фреон (газ, жидкость) / ГВС |
| sensor | проток (л/мин), компрессор 1 и 2 (Гц) |
| sensor | потребляемая мощность (W), выходная мощность (W), COP |
| sensor | состояние, номер расписания, версия прошивки |
| sensor | параметры расписания: Тдома, Тводы, Тгвс, ограничение ККБ, режим ТЭНа, режим ГВС |
| binary_sensor | ТЭН, нагреватель БКН |
| time | внутренние часы устройства |

## Примечания

- Протокол: 64-байтовый SYNC-ответ, контрольная сумма = сумма первых 62 байт.
- Все 16-битные поля little-endian, время/день — BCD.
- Выходная мощность = `(проток/60) × 4186 × (подача − обратка)`.
- COP = выходная мощность / потребляемая.
